# 单目视觉黑痣定位机械臂实施路线（历史阶段计划）

> 本文保留早期单目方案的实施记录，不是当前比赛控制流程。涉及串口、医生选择目标、安全距离或机械臂状态机的内容已经过时；当前业务以根目录 `项目演示(3).md` 为准，唯一正式通信协议为 `视觉协议(5).md`。

## 1. 项目目标

本项目使用 Jetson Nano B01 和单目摄像头，在固定的仿真人脸模型上完成以下闭环：

```text
采集无黑痣基准图
    → 贴上模拟黑痣
    → 检测新增黑色区域
    → 计算黑痣中心坐标
    → 坐标稳定性与安全检查
    → 发送给下位机
    → 机械臂执行安全预定位和对准
```

当前阶段只面向仿真人脸模型和模拟黑痣，不进行真人实验，不控制真实医疗激光。

## 2. 第一版的前提条件

为了先做出稳定、可验证的版本，第一版采用以下约束：

- 使用一个单目摄像头。
- 摄像头、焦距、分辨率和安装角度固定。
- 人脸模型安装在固定底座上，位置和姿态不随意变化。
- 使用稳定、均匀的补光，尽量关闭自动曝光和自动白平衡。
- 黑痣使用可移除、颜色明显的黑色圆点模拟。
- 先输出图像像素坐标 `(u, v)`，验证视觉算法后再转换成机械臂坐标 `(X, Y, Z)`。
- 下位机必须保留急停、限位、工作空间限制和通信超时保护。

如果摄像头或人脸模型移动，旧基准图和坐标映射可能失效，系统必须重新对齐或重新标定。

## 3. 为什么先做相机标定

只判断画面里有没有黑痣时，可以暂时不去畸变；但是项目最终需要返回机械臂坐标，因此相机标定不能省略。

相机标定用于获得：

- 相机内参矩阵。
- 镜头畸变参数。
- 去畸变后的稳定像素坐标。
- 后续像素坐标到机械臂坐标转换所需的基础参数。

标定参数只对特定的摄像头、镜头、焦距和图像分辨率有效。更换其中任何一项后，需要重新标定。

当前工程已有 `calib_capture.py`、`calib_solve.py` 和 15 张旧标定图片，但旧图片只有在摄像头、镜头、焦距和分辨率完全相同时才可复用。正式使用时应优先用当前摄像头重新采集。

## 4. 系统总体架构

```text
单目摄像头
    ↓
图像采集与固定曝光
    ↓
相机去畸变
    ↓
人脸有效区域 ROI
    ↓
当前图像与无黑痣基准图对齐
    ↓
新增暗色区域差分检测
    ↓
面积、圆度、对比度和排除区域过滤
    ↓
连续多帧稳定性判断
    ↓
黑痣像素坐标 (u, v) 与置信度
    ↓
像素坐标到机械臂坐标的标定映射
    ↓
工作空间与状态检查
    ↓
串口发送给 RA6M5
```

## 5. 视觉检测方案

### 5.1 无黑痣基准采集

在人脸模型没有黑痣时连续采集 20～30 帧，完成去畸变和图像对齐后取中值，生成基准图。相比只保存一帧，中值图能减少摄像头噪点和偶发光照变化。

建议保存：

```text
reference/
  clean_face.png           # 无黑痣基准图
  clean_face_mask.png      # 人脸有效区域掩膜
  reference_meta.json      # 分辨率、相机参数摘要和采集时间
```

基准图只允许在以下条件满足时使用：

- 相机参数与当前运行参数一致。
- 人脸模型位置与基准采集时一致。
- 图像对齐误差处于允许范围内。

### 5.2 图像对齐

当前图像与基准图即使只有几像素偏移，也会在眉毛、眼睛和嘴部产生大量伪差异。因此差分前必须对齐。

第一版按以下顺序实现：

1. 摄像头和人脸模型机械固定，使用固定 ROI。
2. 使用图像配准修正小范围平移和旋转。
3. 如果固定效果不够稳定，在人脸底座旁增加 ArUco 标记辅助定位。

对齐失败时不得继续输出黑痣坐标。

### 5.3 黑痣差分检测

黑痣是相对无黑痣基准图新增的暗色区域，核心计算为：

```text
dark_diff = reference_lightness - current_lightness
```

推荐处理流程：

1. 将基准图和当前图转换到 `Lab` 颜色空间。
2. 对 `L` 通道进行适度光照归一化。
3. 计算只保留变暗部分的差分图。
4. 使用阈值生成二值候选区域。
5. 使用开运算和闭运算去除噪声、填补小孔。
6. 提取连通域或轮廓。
7. 根据面积、圆度、长宽比、实心度和局部对比度过滤。
8. 计算候选黑痣中心 `(u, v)`、半径和置信度。

现有 `vision/mole_detect.py` 使用肤色掩膜、black-hat 和形状过滤，可以保留为独立检测器或辅助验证。下一阶段增加基准差分检测器，并在测试中比较两种方法。

### 5.4 排除区域和多帧确认

眉毛、眼睛、鼻孔和嘴部是主要误检来源。虽然这些区域在基准图中已经存在，仍需准备排除掩膜，避免轻微错位产生误报。

候选目标至少满足以下条件才允许输出：

- 位于人脸有效区域内。
- 不在固定排除区域内。
- 面积和形状符合模拟黑痣范围。
- 连续 3～5 帧均被检测到。
- 连续帧中心坐标波动不超过设定阈值。
- 图像对齐成功且置信度达到阈值。

没有有效黑痣时必须输出 `NO_TARGET`。

## 6. 坐标系统

### 6.1 第一阶段：像素坐标

视觉算法首先输出：

```text
target_id, u, v, radius, confidence
```

这一阶段只验证检测准确性，不允许机械臂根据未标定的像素坐标自动接近人脸。

### 6.2 第二阶段：机械臂坐标

单目摄像头不能仅凭一个像素点直接获得三维坐标。人脸又是曲面，不能对整张脸使用一个简单比例或单个平面单应矩阵。

第一版采用固定工位的多点实验标定：

1. 在人脸表面放置 20～40 个临时标定点。
2. 记录每个点的去畸变像素坐标 `(u, v)`。
3. 手动控制机械臂末端对准对应点。
4. 记录机械臂基坐标 `(X, Y, Z)`。
5. 建立 `(u, v) → (X, Y, Z)` 的分区插值映射。
6. 使用未参与建模的测试点测量转换误差。

该映射只对固定的人脸模型、摄像头和安装关系有效。

后续如获得人脸模型 CAD 或三维扫描数据，可升级为相机位姿估计、像素射线与三维网格求交，以及相机坐标系到机械臂基坐标系的外参转换。

### 6.3 安全距离

单目视觉不能可靠测量机械臂末端与人脸表面的实时距离。最终自动运动前，应增加 ToF、激光测距或其他独立距离传感器负责 `Z` 方向安全距离控制。

## 7. Jetson Nano 与下位机职责

### Jetson Nano B01

- 摄像头采集和状态监测。
- 去畸变、图像对齐和人脸 ROI 处理。
- 无黑痣基准管理。
- 黑痣检测、多帧确认和置信度计算。
- 像素坐标到机械臂坐标转换。
- 结果可视化、日志和失败原因记录。
- 按协议向下位机发送目标或 `NO_TARGET`。

### RA6M5 下位机

- 串口数据校验、序号检查和超时处理。
- 机械臂运动控制。
- 急停、限位和距离传感器读取。
- 工作空间、速度和安全距离限制。
- 目标许可和执行状态反馈。
- 数据无效、通信中断或条件不满足时禁止运动和输出。

## 8. 串口通信原则

本文成稿时的 `serial_sender.py` 曾按旧协议发送视觉误差帧，当时帧格式为：

```text
[0xFF][0x05][0x03][dcx_lo][dcx_hi][dcy_lo][dcy_hi][checksum][0xFE]
```

RA6M5 当时的状态回传格式为 `[0xCC][FUNC][VALUE][0xDD]`。这些历史帧已经被 `视觉协议(5).md` 的 `A5 5A + CRC16/MODBUS` 正式链路替代。本文当时曾计划增加：

- 协议版本。
- 消息类型。
- 帧序号。
- 坐标类型标识：像素坐标或机械臂坐标。
- 置信度和状态标志。
- 更可靠的 CRC16。
- 下位机 ACK、拒绝原因和超时机制。

视觉结果无效时必须发送明确的 `NO_TARGET` 状态，不能继续发送上一帧的旧坐标。

## 9. 分阶段实施计划

### 阶段 0：确认硬件与运行环境

任务：

- 确认摄像头是 USB 还是 CSI。
- 确认实际运行分辨率、帧率和画面方向。
- 固定摄像头、人脸模型和补光。
- 确认 Jetson Nano 可以稳定采集图像。

验收：连续运行 10 分钟无断流，画面清晰，无明显自动曝光跳变。

### 阶段 1：相机标定

任务：

- 使用当前摄像头重新采集 15～25 张棋盘格图片。
- 棋盘格覆盖画面中心、四角、不同距离和不同倾角。
- 求解内参和畸变参数并生成 `calib_params.npz`。
- 检查重投影误差和去畸变效果。

现有命令：

```bash
python3 -m jetson_vision.calib_capture \
  --camera 0 --flip none --pattern 6x9 --out calib_images

python3 -m jetson_vision.calib_solve \
  --images calib_images --pattern 6x9 --square-mm 20 \
  --out calib_params.npz
```

验收：标定程序成功识别足够数量的棋盘格图片，去畸变后直线无明显弯曲，并记录重投影误差。

### 阶段 2：建立无黑痣基准

任务：

- 新增基准图采集命令。
- 连续多帧生成无黑痣中值基准图。
- 保存人脸 ROI、排除掩膜和基准元数据。
- 检测相机或人脸明显移动导致的基准失效。

验收：同一工位重复采集时，基准图和当前图对齐稳定；无黑痣状态不产生目标。

### 阶段 3：黑痣差分检测

任务：

- 新增基准差分检测器。
- 输出黑痣中心、大小和置信度。
- 加入面积、圆度、对比度和排除区域过滤。
- 提供原图、对齐图、差分图、二值图和最终结果的调试视图。

验收：在预定黑痣大小和位置范围内稳定检测；无黑痣时不误报；眉毛、眼睛和嘴部不被识别为目标。

### 阶段 4：多帧跟踪与结果状态机

任务：

- 对候选黑痣进行连续帧关联。
- 增加 `NO_TARGET`、`CANDIDATE`、`STABLE_TARGET`、`ALIGN_FAILED` 和 `ERROR` 状态。
- 只有稳定目标才能进入发送状态。

验收：短时噪声和单帧误检不会触发坐标发送；目标稳定后输出坐标波动满足设定要求。

### 阶段 5：像素坐标串口联调

任务：

- Jetson 发送 `(u, v)`、置信度和状态。
- 下位机完成校验、ACK 和超时处理。
- 保存发送记录和下位机响应记录。

验收：连续通信无错误；断开串口或发送坏帧时，下位机进入禁止运动状态。

### 阶段 6：视觉到机械臂坐标标定

任务：

- 采集人脸曲面多点对应数据。
- 建立并保存坐标映射模型。
- 使用独立测试点评估 `(X, Y, Z)` 误差。
- 检测坐标是否位于允许工作空间。

验收：独立测试点误差满足样机要求，映射失效或越界时不输出运动目标。

### 阶段 7：机械臂低速安全对准

任务：

- 增加独立距离测量。
- 先移动到安全预定位点，再低速接近。
- 加入急停、限位、距离阈值、人工确认和通信超时联锁。
- 使用低功率指示光验证最终对准误差。

验收：任何条件不满足时都不能触发执行；多次重复定位结果可记录、可复现。

## 10. 测试指标

视觉阶段至少记录：

- 无黑痣误报率。
- 有黑痣漏检率。
- 黑痣中心像素误差。
- 连续帧坐标标准差。
- 不同位置和不同黑痣尺寸下的检测结果。
- 不同可控光照条件下的检测结果。
- 图像对齐失败率。
- 实时帧率和单帧处理时间。

机械臂阶段至少记录：

- 坐标转换误差。
- 光斑中心与黑痣中心偏差。
- 重复定位误差。
- 串口超时和错误帧拦截结果。
- 急停、限位和距离越界的联锁结果。

具体合格阈值应在首次实机数据采集后确定，不能在没有测量依据时随意承诺。

## 11. 当前工程状态

已经具备：

- USB、CSI 和 GStreamer 相机打开工具。
- 相机测试和抓图脚本。
- 棋盘格采集、内参求解和去畸变模块。
- 基于肤色掩膜、black-hat 和形状过滤的黑痣检测器。
- 单图离线调参和实时预览程序。
- 简单的像素坐标串口发送模块。
- 15 张旧的 `640x480` 棋盘格图片。
- 当前 USB 摄像头的 `640x480` 标定参数 `calib_params.npz`。
- 当前标定共使用 37 张有效图片，全局重投影误差为 `0.2907 px`。
- 无黑痣 30 帧中值基准图和对应元数据。
- 当前图像与基准图的 ECC 小幅配准和失效拦截。
- 基于新增暗色区域、形状与置信度过滤的基准差分检测器。
- 5 帧窗口内的目标稳定性判断。
- 无黑痣实时验证连续 20 帧均为 `NO_TARGET`，无误报和配准失败。
- 实物模拟黑痣实时验证通过：30 帧中 27 帧为稳定目标，中心约为 `(286, 88)`，每帧仅保留 1 个有效候选，无配准失败。
- 已提供一体化状态机 `mole_system.py`：支持相机换位后重采无黑痣基准、进入检测、调试视图、结果保存和配准失效拦截。

尚未完成或尚未确认：

- 人脸曲面像素坐标到机械臂坐标的映射。
- 正式串口协议、ACK 和联锁状态机。
- Jetson Nano 实机完整闭环验证。
