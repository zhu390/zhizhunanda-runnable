# 黑痣识别测试记录

## 测试环境

- 摄像头：`1 dshow MJPG`
- 分辨率：`640x480`
- 帧率设置：`30 fps`
- 标定参数：`calib_params.npz`
- 无黑痣基准：`reference/clean_face.png`
- 坐标系：去畸变并配准到基准图后的像素坐标 `(u, v)`
- 每次测试帧数：30 帧；无目标基线测试为 20 帧

## 暂定验收标准

- 每帧只保留 1 个有效黑痣候选。
- 前 3 帧用于建立稳定历史，之后稳定目标不少于 27/30 帧。
- `ALIGN_FAILED=0`。
- 取下黑痣后无误报。
