# 机械臂点痣上下位机视觉联动系统——答辩完整稿词

> 建议时长：6～8 分钟。方括号中的内容是演讲提示，不需要念出来。

各位老师好，我们的项目是一个基于 Jetson NX 和 RA6M5 的机械臂点痣上下位机视觉联动系统。

本项目以仿真人脸模型作为实验对象，主要实现机械臂与人脸之间的安全测距、左、正、右三视图采集、黑痣自动识别、视觉闭环对准、Qt 人机交互以及激光输出安全联锁。当前系统用于教学、竞赛和仿真模型验证，不面向真人治疗，也不属于医疗器械。

[切换到“项目背景”页面]

我们在设计这个项目时，主要考虑了三个问题。

第一个问题是安全。机械臂在靠近人脸时，不能只依靠固定点位或者预先设定的运动距离，需要实时知道机械臂末端和人脸表面之间还剩多少空间。

第二个问题是精度。黑痣属于小目标，而且仿真人脸上还存在眼睛、眉毛、鼻孔以及光照阴影，这些区域都可能被误认为黑痣。仅使用简单的二值化或者灰度阈值，无法保证识别稳定。

第三个问题是系统联动。视觉识别、Qt 界面、串口通信和机械臂控制不能是几个互相独立的程序，而要组成一个有状态、有确认、有异常处理的完整闭环。

因此，我们采用了“上位机负责视觉和交互，下位机负责运动和安全”的总体方案。

[切换到“系统架构”页面]

系统主要由 Jetson NX、Astra RGB-D 相机、末端 USB 单目相机、Qt 界面、CH340 串口以及 RA6M5 五轴机械臂组成。

上位机是 Jetson NX。它主要负责 Qt 界面、相机采集、YOLO 推理、RGB-D 安全距离计算、末端黑痣识别、目标跟踪、视觉误差计算和串口协议处理。

下位机是 RA6M5。它主要负责机械臂的实时运动、HOME 复位、三视图固化点位、视觉伺服、限位和急停检测，以及激光输出的最终安全裁决。

上下位机通过 CH340 串口连接。Qt 主程序是串口的唯一拥有者，双目和单目视觉都只向 Qt 提供结果，不允许多个程序同时抢占同一个串口。这样可以避免数据帧交叉、命令序号冲突以及心跳竞争。

[切换到“双目视觉”页面]

接下来介绍我们的两级视觉系统。

第一部分是双目，也就是 Astra RGB-D 深度视觉。这里需要说明，我们不是使用 OpenCV 自己计算左右图像视差，而是通过 Orbbec SDK 获取 Astra 的 RGB 图像和 Depth 深度数据，所以更准确的名称是 RGB-D 深度视觉。

在 RGB 图像中，我们使用 YOLO 检测两个类别，分别是机械臂末端 `arm_tip` 和人脸 `face`。当前模型使用 579 张图片进行训练，最佳轮次为第 52 轮，验证集的 mAP50 为 0.995，mAP50-95 为 0.811。

检测完成以后，系统根据 RGB 和 Depth 的相机内参、畸变参数以及二者之间的外参，将 RGB 检测区域映射到 Depth 数据中。我们没有只读取检测框中心的一个深度值，因为单点深度容易受到空洞和噪声影响，而是分别提取机械臂末端区域和人脸区域的三维点云。

深度像素通过相机内参转换成三维坐标，然后计算两个目标表面之间的保守净距。因此界面显示的不是“相机到人脸的距离”，而是“机械臂末端到人脸表面的三维净距”。

为了降低深度数据跳动，我们还加入了安全偏置的一维卡尔曼滤波。距离突然减小时，系统立即采用新的较小距离，避免滤波延迟危险；距离突然增大时，则需要多帧逐渐确认，防止偶发深度噪声虚报安全。

在正式流程的公共测距位置，Jetson 会把多个新鲜且有效的安全距离样本发送给 RA6M5，RA6M5 完成本轮距离安全锁存。锁存之后，当前正式协议不再持续发送 `SAFE_DISTANCE`，但 Jetson 仍然在本地持续计算 RGB-D 净距。当净距低于当前设置的 120 毫米时，Jetson 会发送 `ABORT_HOLD`，要求 RA6M5 关闭输出并原地安全保持。

所以，双目视觉主要解决的是：机械臂在哪里、人脸在哪里、两者相距多远，以及当前流程是否可以安全继续。

[切换到“末端单目视觉”页面]

第二部分是机械臂末端单目视觉。末端相机距离目标更近，黑痣在画面中的像素尺寸更大，所以它主要负责黑痣精细识别和视觉对准，不负责实际安全深度判断。

末端视觉首先识别人脸区域，只在人脸有效范围内寻找黑痣，避免背景、机械结构和支架进入候选区域。

接着，系统对眼睛设置硬安全掩膜。因为眼区属于绝对禁止定靶区域，即使某个黑点在外观上很像黑痣，也不能被系统选为目标。对于鼻子、嘴巴和眉毛区域，我们没有全部直接屏蔽，因为真实黑痣也可能出现在这些区域附近。

在人脸有效区域中，算法根据灰度、局部对比度、面积、半径、圆度、实体度和长宽比等特征提取暗斑候选。细长的眉毛、面积过大的眼睛以及形状不规则的阴影会被降低优先级或者过滤。

为了进一步解决鼻孔和固定阴影误检问题，我们建立了无黑痣基准图库。目前基准图库包含正脸 183 张、左脸 120 张、右脸 130 张，共 433 张图片。运行时，系统会选择与当前角度和亮度相似的无痣图片，判断某个区域是人脸原来就存在的暗区，还是当前新出现的黑点。

基准图并不是简单逐像素相减，因为机械臂位置、角度和光照会有小幅变化。系统先进行相似图匹配，再比较候选附近的局部新增暗度，并与几何特征共同评分。

检测出候选以后，系统不会立即控制机械臂。候选必须连续多帧出现，并且位置、半径和持续时间满足稳定条件，才会分配稳定的 `track_id`。

开始定靶后，系统还会建立会话级目标身份锁。它通过 `track_id`、目标位置、半径、人脸归一化坐标以及附近歧义候选，持续判断当前识别结果是不是刚才锁定的同一颗黑痣。即使检测器候选排序发生变化，也不会自动切换到鼻孔或者另一颗黑痣。

这部分可以用一句话总结：候选检测解决“哪里像黑痣”，目标身份锁解决“是不是刚才那一颗黑痣”。

[切换到“视觉闭环”页面]

目标稳定锁定以后，Jetson 会计算目标相对激光标定参考点的像素误差。

其中，`dcx` 等于黑痣 X 坐标减去激光参考 X 坐标，`dcy` 等于黑痣 Y 坐标减去激光参考 Y 坐标。

这里使用的不是图像中心，而是在实际工作距离下测量得到的激光参考像素。因为相机光轴、激光安装位置、工作距离以及人脸曲面都会产生系统偏差，所以更换相机、分辨率、安装位置或者工作距离以后，都需要重新标定。

Jetson 周期发送 `VISION_ERROR`，RA6M5 根据 `dcx` 和 `dcy` 调整机械臂。只有误差连续多帧满足阈值，RA6M5 才会回传 `ALIGN_DONE`。

如果目标突然丢失、结果过期、候选不稳定或者出现多目标歧义，Jetson 不会继续复用旧坐标，也不会伪造 `dcx=0、dcy=0、valid=1`，而是短时间等待同一目标恢复，或者发送 `valid=0`。RA6M5 收到无效视觉或者视觉超时后，会停止对准或关闭输出，等待新的可靠视觉结果。

我们的视觉原则是：宁可漏检停止，也不能误检点错。

[切换到“Qt与通信协议”页面]

Qt 界面把整个上下位机流程组织起来，包括开始测距、三视图采集、视图选择、开始定靶、安全停止、完成返回 HOME，以及双目距离、末端识别、串口状态和机械臂状态显示。

串口采用统一二进制协议，帧中包含 `A5 5A` 帧头、版本、消息类型、命令序号、数据长度、有效载荷和 CRC16 校验。

每个新的控制命令都有独立的 `SEQ` 序号。RA6M5 接收到命令以后，先返回同序号的 `COMMAND_ACK`，动作真正完成以后，再返回对应的业务状态。Qt 只有收到真实状态回传才会进入下一阶段，不能使用固定延时假设机械臂已经到位。

Jetson 还会每 100 到 200 毫秒发送一次心跳。如果 RA6M5 超过大约 600 毫秒没有收到合法心跳，就会关闭输出、中止自动运动并进入安全保持。

[切换到“完整流程”页面]

系统的完整工作流程如下。

第一步，操作者在 Qt 点击“开始”。Jetson 请求 RA6M5 回到公共测距位，收到真实到位状态后，RGB-D 才开始发送新的安全距离样本。

第二步，距离安全锁存以后，操作者点击“采集人脸图”。RA6M5 依次到达左视图、正视图和右视图点位。每个点位都必须收到到位回传以后，Jetson 才保存对应图片，最后机械臂返回 HOME。

第三步，操作者从三张图片中选择需要处理的视图。RA6M5 移动到对应固化点位，末端单目相机开始实时识别并稳定锁定黑痣。

第四步，操作者点击“开始点痣”。Jetson 发送 `TARGET_CTRL START`。只有收到 RA6M5 的 `TARGET_CTRL_ON` 和 `TARGET_READY` 后，Jetson 才开始周期发送有效的 `dcx` 和 `dcy`。

第五步，RA6M5 根据视觉误差完成闭环对准，并回传 `ALIGN_DONE`。这个状态只代表对准完成，并不代表可以直接输出。

第六步，只有心跳正常、距离安全已经锁存、位姿有效、视觉结果新鲜、误差在阈值内、没有急停和限位故障，并且操作者按住物理 P000，RA6M5 才允许 P801 输出。操作者松开 P000、视觉丢失或者误差重新超限，P801 都会立即关闭。

最后，操作者点击“完成/返回”，Jetson 发送返回 HOME 请求。只有 RA6M5 完成复位并回传 `RETURN_HOME_DONE`，Qt 才显示流程完成并返回工作台，可以开始下一轮。

[切换到“创新点”页面]

我们认为本项目主要有五个特点。

第一，采用 RGB-D 全局安全感知和末端单目精细定位的两级视觉结构，让安全距离与定位精度分别由更合适的传感器完成。

第二，针对固定仿真人脸建立分视图无痣基准图库，通过新增暗度判断降低鼻孔、眉毛和阴影误检。

第三，加入多帧稳定跟踪和会话级目标身份锁，防止机械臂运动过程中自动切换目标。

第四，采用失效安全策略。视觉不确定时不复用旧坐标、不伪造有效结果，而是停止推进并交由 RA6M5 安全保持。

第五，将 Qt、视觉算法、可靠串口协议和 RA6M5 安全状态机真正组成上下位机闭环，而不是单独展示一个识别程序或者一个机械臂动作。

[切换到“不足与展望”页面]

目前项目仍然存在一些不足。

首先，当前系统只在仿真人脸模型上进行验证，无痣基准图库对模型、光照和相机安装环境有一定依赖。

其次，黑痣属于小目标，后续还需要扩充不同大小、不同位置、不同光照和不同工作距离的数据，并建立末端识别成功率、误检率和目标锁定时间等量化指标。

再次，人脸属于曲面，固定激光像素偏置无法完全描述所有位置。后续可以增加左、正、右分视图偏置、不同工作距离标定，或者使用三维曲面重建进行补偿。

最后，当前正式协议采用初始安全距离锁存加 Jetson 本地连续守卫。未来如果需要让 RA6M5 全流程持续接收安全距离，还需要同时升级上下位机协议和安全状态机，不能由 Jetson 单方面开启。

[切换到“总结”页面]

总结来说，我们实现的不是一个简单的黑点识别程序，而是一套机械臂点痣上下位机视觉联动系统。

Jetson 上位机负责 Qt 人机交互、RGB-D 安全感知、末端黑痣识别和视觉误差计算；RA6M5 下位机负责机械臂实时运动、视觉伺服以及激光输出的最终安全裁决。双目和单目视觉通过统一协议与状态机组成完整闭环，从而实现从安全测距、三视图采集、目标识别、机械臂对准到完成返回 HOME 的完整演示流程。
